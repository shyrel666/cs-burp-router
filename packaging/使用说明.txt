====================================================================
                CS-Burp-Router 新手 1 分钟速查手册
====================================================================

一句话说明：
  用来给 Windows 桌面客户端（C/S 程序）抓包。
  网页 / 接口流量自动进 Burp，数据库和其他连接自动放行，不卡死、不超时。


一、第一次使用：照着这 4 步就能抓到包
--------------------------------------------------------------------
【第 1 步】在 Burp Suite 打开「隐形代理」（必做，否则抓不到或报错）
  Burp Suite -> Proxy -> Proxy settings -> Proxy listeners
  -> 选中 127.0.0.1:8080 -> 点击 Edit -> 切到 Request handling
  -> 勾选 [Support invisible proxying] -> 点 OK 保存。

【第 2 步】启动本工具
  右键 cs-burp-router.exe -> 选择【以管理员身份运行】。
  启动后会自动弹出浏览器打开本地控制台（http://127.0.0.1:18080）。
  （没有管理员权限也可直接双击运行，详见第五节 SOCKS5 模式）

【第 3 步】一键找出正在发包的进程并接管
  1. 先在目标客户端里点一下登录或任意功能，让它产生联网；
  2. 在控制台点【选择运行进程】，勾选【仅看活跃外联进程】；
  3. 排在最前面带连接数如 (5) 和远端地址的进程就是正在发包的进程，勾选它；
  4. 点击【启动接管】，即可在 Burp Proxy -> HTTP history 中看到包。

【第 4 步】抓 HTTPS 时一键安装 Burp 证书
  先确保 Burp 已启动，点控制台顶部【安装证书】（或【路由设置】->【一键安装证书】），
  核对页面显示的 SHA-256 指纹与 Burp 一致后确认导入即可。
  若客户端使用独立证书库（如部分 Java 客户端），可点【下载 .der】手动导入。


二、日常抓包高频操作（遇到情况直接照着点）
--------------------------------------------------------------------
1. 不知道哪个子进程在发包
   打开【选择运行进程】-> 勾【仅看活跃外联进程】-> 可直接搜服务器 IP/端口，
   短连接可边操作客户端边点右上角【刷新】。

2. 某个连接卡顿，或不想让 Burp 拦它
   在连接表找到这一行，点最右侧【强制直连】即可立即生效（跳过 200ms 探测）。
   想恢复时点【取消覆盖】，或在【路由设置】->【当前覆盖规则】里一键【清空全部】。

3. HTTP/HTTPS 跑在 3306 / 1433 等数据库端口，被默认放行了
   无需改全局白名单，在连接表找到这一行直接点右侧【强制进 Burp】即可突破放行。

4. 内网直连裸 IP 看不清域名 / 老客户端 HTTPS 握手失败
   - 连接表【目标地址 / SNI】列会自动把真实域名显示在主行（带 SNI 标签），
     点击主行复制域名，点击次行复制 IP:端口。
   - 若【识别协议】列出现橙色【TLS 1.0 (弱加密)】或【TLS 1.1 (弱加密)】，
     去 Burp 的 Settings -> Network -> TLS 勾选对应旧版协议即可恢复抓包。

5. 客户端报错，想秒确认是不是抓包导致的
   点顶部【全局直连】立刻让所有新连接绕过 Burp；验证完再点【恢复智能分流】。


三、遇到问题？10 秒速查
--------------------------------------------------------------------
- 表格显示 Burp，但 Burp 里没收到包：
  检查 Burp 是否勾选了 Support invisible proxying，且端口与【路由设置】一致。

- 启动接管后连接表一直是空的：
  1) 勾【仅看活跃外联进程】确认有没有选错子进程；
  2) 目标是内网裸 IP 时，进【路由设置】把域名匹配策略改为【纯 IP 适配 ("")】，
     再点【更新重启】。

- HTTPS 提示证书错误或握手失败：
  点顶部【安装证书】；如果协议列有橙色【弱加密】标签，在 Burp 开启 TLS 1.0/1.1。

- 非标准端口数据库/私有协议每次都很慢：
  在连接表该行点【强制直连】，或在【路由设置】把端口加入【直连白名单端口】。

- 不小心把浏览器关了怎么重开控制台：
  切回本程序的黑色终端窗口，直接按 Enter 自动重新打开；输入 link 回车可查看链接。


四、测试结束撤场清理
--------------------------------------------------------------------
1. 点击控制栏【停止】结束进程接管（或直接按 Ctrl+C 退出程序，会自动清理配置）；
2. 打开【路由设置】->【Burp CA 根证书】-> 点击【卸载清理】，一键移除系统根证书。


五、无管理员权限用法（普通用户 SOCKS5 模式）
--------------------------------------------------------------------
1. 直接双击运行 cs-burp-router.exe（无需管理员权限，不用点【启动接管】）；
2. 在目标客户端或 JVM 参数中配置 SOCKS5 代理为 127.0.0.1:10808，例如：
     -DsocksProxyHost=127.0.0.1 -DsocksProxyPort=10808
3. 控制台的智能分流、SNI 识别、弱加密提醒、单目标覆盖均完整可用。


六、默认端口、快捷键与命令行参数
--------------------------------------------------------------------
- 本地 SOCKS5 入口 : 127.0.0.1:10808
- 默认 Burp 地址   : 127.0.0.1:8080  （支持在【路由设置】热修改）
- 本地 Web 控制台  : http://127.0.0.1:18080
- 默认直连白名单   : 21, 22, 25, 1433, 1521, 3306, 5432, 6379, 27017
- 控制台快捷键     : 按 / 聚焦搜索框（支持搜地址/SNI/弱加密/覆盖），按 Esc 关闭弹窗

常用启动参数：
  -listen string      自定义 SOCKS5 回环监听地址 (默认 "127.0.0.1:10808")
  -burp string        自定义 Burp 代理地址 (默认 "127.0.0.1:8080")
  -web string         自定义 Web 控制台回环监听地址 (默认 "127.0.0.1:18080")
  -bridge-bin string  自定义 ProxyBridge_CLI.exe 路径
  -no-browser         不自动打开浏览器，在终端直接打印带凭据的完整链接
